## 02-ollama模型说明.py

**你记的重点：**

**1. ollama 是什么：**
- 第三方的包，用 `pip install` 安装 Python 库
- 本地工具，`.exe`（Windows）/ `.dmg`（Mac）安装桌面端
- 安装后启动本地服务器，地址 `127.0.0.1:11434`
- 命令行用法：`ollama run '模型名'` → 发送消息交互

**2. 几种交互方式对比：**
- **apifox**：json 请求 → 借助后端接口文档发送对应请求获取数据
- **ollama 工具本身**：命令行 / 可视化 chatbox 界面
- **streamlit 框架 + ollama 第三方包**：
  1. `pip install` 安装依赖
  2. streamlit 创建前端页面 → `streamlit run **.py`
  3. 启动服务（`localhost:8501`）打开网页
  4. 提供组件：title / image / table 等标签

**3. 核心调用格式：**
```python
ollama.chat(model='模型', messages=[{
    'role': 'user',   # 角色
    'content': '聊天内容',
}])
```

**4. 下面学习目标：**
- 实现多轮对话
- 聊天存储器 → 不只是服务器
- 对应的 sql 配合接口
- 消息存储（持久化）

## chat_utils.py

**你记的重点：**
- 该模块充当**聊天机器人的后端模块**
- 接收前端 Streamlit 传来的用户问题 → 交给大语言模型（deepseek、qwen）→ 获取模型返回的结果 → 返回给前端

**需求：**
1. 构建一个基于大模型的本地智能聊天机器人
2. 请求模块：向服务器请求数据，调用模型获取结果

**模块职责：**
- `chat_utils` 模块：
  1. 接受前端 Streamlit 传过来的用户问题
  2. 交给大预言模型，获取结果，并返回

**步骤：**
1. 导包 `import ollama`
2. 定义函数请求拿结果
3. 测试函数

**核心代码：**
```python
import ollama

def get_response(prompt):
    # 显式指定 host，避免 localhost 解析到 IPv6
    client = ollama.Client(host='http://127.0.0.1:11434')
    response = client.chat(
        model='deepseek-r1:1.5b',
        # messages=[{'role': 'user', 'content': prompt}]
        # 换成 prompt，有我们说的话、AI说的话，是一个消息列表
        messages=prompt
    )
    return response.message.content
```

**关键点：**
- `ollama.Client(host='http://127.0.0.1:11434')` 显式指定 host，避免 localhost 被解析到 IPv6 导致连不上
- `model='deepseek-r1:1.5b'` 指定使用的模型
- `messages=prompt`：这里 prompt 不是单条字符串，而是**完整的消息列表**（包含历史对话），让模型有上下文能力
- 返回 `response.message.content` 取模型回复的文本内容
- 底部用 `if __name__ == '__main__':` 做测试，单独运行时可以输入问题测试

## chat_main.py

**你记的重点：**
- 该模块充当聊天机器人的**前端** → 接收用户输入的问题
- 调用 `chat_utils` 模块中的 `get_response()` 函数获取模型结果
- 最终通过 streamlit 在前端展示

**整体架构：前端（chat_main.py / streamlit）→ 后端（chat_utils.py / ollama）**

**#1. 导包：**
```python
import streamlit as st                                    # 搭建聊天界面
from langchain.memory import ConversationBufferMemory     # 聊天记录存储区
from chat_utils import get_response                       # 自定义模块，获取模型结果
```
- `langchain` 库：聊天机器人核心的模块
- `ConversationBufferMemory`：聊天记录存储区，专门存储和管理多轮对话历史

**#2. 页面标题：**
```python
st.title("聊天")
```

**#3. 会话状态初始化：**
- `st.session_state` 存储会话状态数据的字典（存储会话数据）
- 判断是否有历史消息记录对象，如果没有就创建：
```python
if 'memory' not in st.session_state:
    st.session_state.memory = ConversationBufferMemory()  # 创建记忆对象
    # 添加机器人欢迎语
    st.session_state.messages = [{"role": "assistant", "content": "你好，我是你的AI助手，有什么可以帮助到你的么？"}]
```

**#4. 遍历历史消息显示到页面：**
```python
for message in st.session_state.messages:
    with st.chat_message(message['role']):      # 根据角色（user/assistant）渲染不同气泡
        st.markdown(message['content'])          # 消息内容支持 markdown
```
- `st.chat_message(角色)`：streamlit 提供的聊天消息容器，显示当前角色的内容

**#5. 获取用户输入：**
```python
prompt = st.chat_input("请输入你的问题...")
```

**#6. 处理用户输入（if prompt）：**

**6.1 把用户输入添加到 messages 列表（消息历史记录）：**
```python
st.session_state.messages.append({"role": "user", "content": prompt})
```
- Todo：发送给服务器 → 数据库存储（和渲染没关系）

**6.2 在页面上显示用户输入的消息：**
```python
with st.chat_message("user"):
    st.markdown(prompt)
```

**6.3 调用模型获取回复（带加载动画）：**
```python
with st.spinner('Ai正在思考中...'):
    # 把完整的对话历史记录传过去，而不是自己说的内容（否则模型无法推理、无上下文能力）
    response = get_response(st.session_state.messages)
```
- `st.spinner()`：显示加载动画，思考时转圈圈
- **关键**：传 `st.session_state.messages`（完整对话历史），不是单条 prompt，这样模型才有上下文/多轮对话能力

**6.4 将模型回复添加到历史记录并渲染：**
```python
st.session_state.messages.append({"role": "assistant", "content": response})
st.chat_message("assistant").markdown(response)
```

## 整体知识脉络

> **ollama 本地大模型**：安装 → 启动服务(127.0.0.1:11434) → Python 库调用
> **langchain 框架**：ConversationBufferMemory 管理对话记忆，pip 指定版本安装
> **前后端分离架构**：
> - 前端 `chat_main.py`：streamlit 界面 + session_state 存历史消息 + chat_message 渲染气泡
> - 后端 `chat_utils.py`：ollama.Client 连接模型 → 传完整消息列表 → 返回回复
> **多轮对话核心**：每次把完整 messages 列表传给模型，模型据此理解上下文
