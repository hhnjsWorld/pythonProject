- 期望输出：`{3: ['bat','cat','dog'], 5: ['apple'], 8: ['elephant']}`
- 你写了三种写法：

  2. **循环写法**：`get_types(l)` 函数，遍历列表，每次造一个字典 `{'name': word}` append 进去

- 核心思路：**先收集键（长度），再按键分组值（单词）**

## 04-文件基本操作回顾.py

**你记的重点：**
- 文件分两大类：**字符形式（文本）** 和 **字节形式（二进制）**，可以组合使用 `+`

**文本模式（支持编码，处理 txt）：**

| 模式 | 作用 | 特点 |
|------|------|------|
| `r` | 只读 | 文件不存在直接报错，不能写 |
| `w` | 覆盖写 | 文件不存在就新建，存在就清空原内容从头写 |
| `a` | 追加写 | 文件不存在就新建，存在就在末尾追加，不清空 |

**二进制模式（rb/wb/ab，不支持编码，处理图片/视频/音频）：**

| 模式 | 作用 |
|------|------|
| `rb` | 二进制只读，返回 bytes 字节 |
| `wb` | 二进制覆盖写 |
| `ab` | 二进制追加写 |

**补充小知识点：**
1. 带 `b` 的模式（rb/wb/ab）→ 字节模式，**不能写 encoding 参数**
2. `r/w/a` 不带 b → 文本字符模式，建议带上 `encoding='utf-8'` 防止中文乱码
3. 增强模式：`r+` 读写、`w+` 写读、`a+` 读写

## 05-案例-拷贝文件.py

**你记的重点：**
- **需求1：拷贝图片** hand.png → hand1.png
  1. 源文件用 `rb` 模式打开（二进制只读）
  2. 目标文件用 `wb` 模式打开（二进制写入，自动创建）
  3. `while True` 循环，每次 `read(1024)` 读 1024 字节
  4. 读到 `len(data) == 0` 说明读完了，`break`
  5. 将读到的二进制数据 `write()` 写入目标文件
  6. 最后 `close()` 两个文件释放资源

- **需求2：拷贝文本** 1.txt → 2.txt
  - 第一步：先创建 1.txt 并写入内容（`w` 模式）
  - 第二步：源文件 `r` 模式打开，目标文件 `w` 模式打开
  - 同样用 `while True + read(1024)` 循环读取写入
- **关键**：读取长度一般用 1024 的整倍数，分块读写避免大文件占内存

## 07-with_open语句.py

**你记的重点：**
- `with open('路径', '模式', '码表') as 别名:` 语法
- **特点**：语句体执行结束后，with 后边定义的变量会**自动被释放**（自动 close），不用手动关
- 可以同时打开多个文件：
  ```python
  with open('a.txt', 'r', encoding='utf-8') as src_f1, \
       open('b.txt', 'w', encoding='utf-8') as src_f2:
      # 操作代码
  ```
- 同样的文字反转应用题，用 with 写法更简洁安全
- **with 是推荐写法**，避免忘记 close 导致的资源占用

## 08-异常捕获.py

**你记的重点：**
- 异常 = 程序运行时发生的错误，Python 遇到无法处理的情况会抛出异常，不捕获就终止
- 作用：防止程序崩溃、提升用户体验、给错误提示/记录日志

**四关键字语法速查表：**

| 关键字 | 作用 |
|--------|------|
| `try:` | 放可能出问题的代码 |
| `except Exception as e:` | 出问题后的解决方案，捕获异常并处理 |
| `else:` | 没有出问题（没执行 except）时执行这里 |
| `finally:` | 无论是否出问题**都会执行**，一般用于释放资源 |

**执行流程**：try → 出问题？是→except；否→else → 最后都走 finally
- 标准代码模板：try/except/else/finally 四块齐全
- 你练了：输入年龄转 int，输错（如 'abc'）捕获 ValueError 提示重新输入
- `except ValueError` 可以捕获特定类型异常，比笼统的 Exception 更精准

## 09-内置模块导入方式.py

**你记的重点：**
- 四种导入方式：

1. **`import 模块名`** —— 导入整个模块，调用用 `模块名.功能名()`
   - 例：`import os` → `os.getcwd()`

2. **`import 模块名 as 别名`** —— 给模块起个短名，方便书写
   - 例：`import os as o` → `o.getcwd()`

3. **`from 模块名 import 功能1, 功能2`** —— 只导入需要的函数，直接用函数名
   - 例：`from math import ceil, floor` → 直接 `ceil(10.8)`、`floor(10.1)`
   - `ceil` 向上取整，`floor` 向下取整

4. **`from 模块名 import *`** —— 导入所有内容（**不推荐！** 容易命名冲突）
   - 例：`from time import *` → 直接 `sleep(3)`

- 你还注释了 time 模块：`time.sleep(3)` 延时器、`time.time()` 时间戳（从1970年至今的秒数）

## 10-自定义模块导入方式.py

**你记的重点：**
- **模块（Module）**就是一个 `.py` 文件，里面包含一组相关的函数、变量、类
- 模块的作用：
  1. **代码复用** —— 写好的函数所有项目都能直接用
  2. **避免命名冲突** —— 不同模块可以有同名函数，通过 `模块名.函数名()` 区分
  3. **逻辑清晰易维护** —— 按功能划分到不同模块

- 模块三大来源：
  1. **内置模块** —— Python 自带，直接 import（random, os, math, time...）
  2. **自定义模块** —— 自己创建的 .py 文件
  3. **第三方模块** —— 别人开发的，需要 `pip install` 安装（requests, flask）

- 自定义模块步骤：
  1. 创建一个 .py 文件（如 `my_sum.py`），在里面写函数
  2. 在另一个文件中 `import my_sum` 或 `from my_sum import add1`
  3. 调用：`my_sum.add1(10, 20)` 或直接 `add1(10, 20)`

- 你详细整理了常用内置模块：
  - **random**：`randint(1,100)` 随机整数、`choice(列表)` 随机选一个
  - **math**：`math.pi` 圆周率、`sqrt(16)` 平方根、`ceil(3.2)` 向上取整、`floor(3.9)` 向下取整
  - **time**：`time()` 时间戳、`sleep(1)` 暂停、`strftime()` 格式化时间
  - **os**：`getcwd()`、`listdir()`、`mkdir()`、`rename()`、`remove()`、`rmdir()`
  - **json**：`dumps(data)` 字典转JSON字符串、`loads(str)` JSON字符串转字典
  - 第三方模块常见别名：`import numpy as np`、`import pandas as pd`

## 11-__name__的说明.py

**你记的重点：**
- 每个 `.py` 文件都有一个内置变量 `__name__`
- **当文件被直接运行时**：`__name__ == '__main__'`
- **当文件被其他模块导入时**：`__name__ == 模块的文件名`（如 `'my_sum'`）
- 标准写法：把主程序逻辑放在 `if __name__ == '__main__':` 内部
- 模块的功能函数放在外面
- 这样做的好处：**自己运行时能看到测试代码，别人导入时不会执行测试代码**
- 建议所有文件/模块都以 `if __name__ == '__main__':` 开始主程序逻辑

## flower_function.py

**你记的重点：**
- 这是一个**自定义模块**，封装水仙花数相关函数，供其他文件导入复用

**函数1：`flower_fn(prompt)`** —— 判断单个数字是否为水仙花数
- `while True` 循环获取输入
- `try/except` 捕获输入异常
- 校验必须是 100~999 的三位数
- 核心算法：`for i in str(value)` 遍历每一位数字，`int(i) ** 3` 立方累加
- 比较 `value == result`，成立返回"水仙花数字成立"，不成立提示不成立

**函数2：`flower_fn1(x, y)`** —— 求两个数之间所有水仙花数
- 输入两个数字确定区间
- 校验区间有效性
- `for num in range(value1, value2)` 遍历区间
- 取各位：`h = num // 100`（百位）、`t = num // 10 % 10`（十位）、`u = num % 10`（个位）
- 判断 `num == h**3 + t**3 + u**3`，符合就加入列表
- 列表为空返回"空的"，否则返回结果列表
- 底部用 `if __name__ == '__main__':` 做测试代码，导入时不会执行
